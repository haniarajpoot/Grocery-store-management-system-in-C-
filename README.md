# 🛒 Grocery Management System (C++)

## 📖 Overview

The Grocery Management System is a console-based application developed in C++ using Visual Studio. It is designed to simplify grocery store operations by managing products, inventory, customer records, billing, and sales.

This project was developed as part of my Computer Science coursework to strengthen my programming and problem-solving skills.

---

## ✨ Features

- Product Management
- Inventory Management
- Customer Record Management
- Billing System
- Sales Processing
- Discount Calculation
- Item Return Functionality
- File Handling
- Menu-Driven Interface

---

## 🛠 Technologies Used

- C++
- Visual Studio 2022
- Object-Oriented Programming (OOP)

---

## 🚀 How to Run

1. Download or clone the repository.
2. Open `grocery store management system.sln` in Visual Studio 2022.
3. Build the project.
4. Run the application.
